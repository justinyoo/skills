# Technical Writing in English

English | [한국어](README.ko.md)

## What this skill is for

Draft, proofread, revise, or review English technical documents and other English writing while preserving meaning, evidence, terminology, and the author's voice. Existing document and project styles take priority; US English is the default for new documents without a specified variant. No scripts, packages, or external correction service are required.

ISO 24495-1 and ASD-STE100 offer complementary perspectives, but neither alone covers this skill's full scope. The skill draws on selected principles without claiming standards conformance or certification. The source register also lists dictionaries and public-sector and publication style guides as context-specific references, not universal rules. See the [source comparison and usage conditions](references/sources.md) and [SKILL.md](SKILL.md) for the authoritative workflow.

## Usage

In a GitHub Copilot CLI session, try:

```text

```
