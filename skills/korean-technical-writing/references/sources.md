# 근거, 비교 및 사용 조건

한국어 글쓰기의 판단 근거와 이 스킬의 편집 정책을 구분한다.
아래 내용은 공개 자료를 바탕으로 직접 작성한 요약과 적용 방침이다.
표준의 조문, 공식 비교표나 사전의 복제물이 아니며 기관의 인증을 뜻하지 않는다.
사용 조건의 공식 웹 안내는 2026-10-29에 확인했다. 이후 변경될 수 있으므로 실제
자료를 재사용할 때는 해당 자료의 최신 안내를 확인한다.

## Comparison

사전 연구의 세 근거 역할 비교를 한국어 전용 목적에 맞게 정리한 표다.
ASD-STE100 또는 ISO 24495-1 단독으로 충분하지 않다는 설명은 이 스킬의 목표
범위에 관한 것이지 각 표준의 본래 목적이나 가치를 부정하는 뜻이 아니다.

| 자료 | 참고하는 역할 | 단독으로 충분하지 않은 이유 |
| --- | --- | --- |
| ISO 24495-1 | 독자에게 필요한 내용인지, 정보를 찾고 이해하며 사용할 수 있는지를 문서 전체 차원에서 점검한다. | 한국어 맞춤법, 띄어쓰기, 자연스러운 표현이나 기술 사실의 정확성을 그 자체로 보장하지 않는다. |
| ASD-STE100 | 용어의 일관성, 조건과 동작의 명확성, 모호성 감소 등의 원리를 선별 참고한다. | 영어 통제 언어의 규칙과 사전을 한국어에 그대로 적용할 수 없으며 한국어 결과물의 STE 준수를 주장할 수 없다. |
| 국립국어원 어문 규범 및 관련 자료 | 한국어 표기, 띄어쓰기, 표준어, 문장 부호와 분야별 용어 판단의 근거를 제공한다. 자료마다 적용 범위를 구분한다. | 표기가 바르다는 것만으로 문서 구조, 독자 이해와 활용, 기술 사실의 정확성이 보장되지는 않는다. |

세 근거를 함께 사용해도 기술 사실이 자동으로 검증되지는 않는다. 제품 사양,
관찰 자료와 분야별 전문 근거를 별도로 확인해야 한다. 규범은 표기를, 사양은
기술 사실을, 문서 자체 규칙은 그 적용 범위의 일관성을 판단하는 데 사용한다.

ISO의 공개 소개는 기술 글쓰기와 여러 언어에 적용되는 범위를 설명한다.
관련성, 찾기 쉬움, 이해와 활용이라는 독자 관점은 아래의 공개 해설도 참고했다.
이 문서의 한국어 점검 방법은 스킬 작성자의 적용 방침이며 ISO 조문 번역이 아니다.
STE 역시 전체 규칙과 사전을 가져온 것이 아니라 공개 설명에서 유용한 원리를
선별 참고한 것이다.

## Korean-specific foundations

| 한국어 근거 | 스킬에 적용하는 내용 | 주의할 점 |
| --- | --- | --- |
| 한글 맞춤법 제41-42항 | 조사와 의존 명사의 문법적 기능에 맞는 띄어쓰기. | 같은 모양의 문자열을 기계적으로 치환하지 않는다. |
| 제43항 | 단위 명사의 띄어쓰기 원칙과 숫자 결합 등의 허용. | `2시간`을 무조건 오류로 보거나 코드와 모든 단위 기호에 같은 규칙을 적용하지 않는다. |
| 제47항 | 보조 용언의 원칙, 붙여쓰기 허용과 예외. | 모든 보조 용언을 무조건 띄거나 붙이지 않는다. |
| 제50항과 해설 | 전문 용어의 띄어쓰기와 허용되는 붙여쓰기. | `무역 수지`와 `무역수지`의 허용 여부를 문서의 일관성 선택과 구분한다. 일반 사전에 없다고 전문 용어를 오류로 단정하지 않는다. |
| 표준어 규정 및 사전 | 문맥에 맞는 표준 형태와 어휘의 의미. | 인용, 의도적인 지역어와 저자의 목소리를 일률적으로 표준화하지 않는다. |
| 외래어 표기법 | 외래어를 한국어로 적는 경우의 규칙. | 코드, 제품명, 정확한 UI 표기를 임의로 번역하거나 이름을 만들어 붙이지 않는다. |
| 한글 맞춤법 부록 문장 부호 | 부호의 용법과 허용되는 대체 표기. | 자판 친화 기본값은 편집 정책이지 다른 유효한 부호의 금지가 아니다. |

한국어에 맞게 적용한다는 것은 영어 표면 형식을 옮기는 일이 아니다.

| 목적 | 한국어 적용 | 피해야 할 기계적 이식 |
| --- | --- | --- |
| 명확한 지시 | 필요한 주체, 조건, 동작과 대상을 드러낸다. | 자연스러운 주어 생략까지 오류로 보고 매번 주어를 반복한다. |
| 읽기 쉬운 문장 | 중첩된 조건과 긴 수식을 풀고 독립적인 동작을 구분한다. | 영어 단어 수 제한을 같은 숫자의 한국어 어절 제한으로 바꾼다. |
| 정확한 의미 | 의무, 허용, 가능성, 부정과 범위를 보존한다. | 피동문이나 `할 수 있다`를 일괄 삭제한다. |
| 일관된 용어 | 분야와 문서의 정의를 확인하고 낯선 개념은 설명한다. | 영어 통제 사전을 한국어 허용어 목록으로 만들거나 쉬운 다른 개념으로 대체한다. |
| 적절한 문체 | 목적과 독자, 기존 글의 시점과 격식을 존중한다. | 모든 글에 명령형, 하나의 종결 표현이나 매뉴얼 형식을 강제한다. |

자판 친화 정책은 새 본문에 쉼표, 따옴표, 괄호와 물결표 등을 우선하는 선택이다.
가운뎃점의 묶음 관계, 범위의 끝값과 부호, 정확한 인용과 정식 명칭은 보존한다.
문장 부호 규정이 허용하는 대체와 Markdown에서 직선 따옴표를 고르는 편집 선택도
구분한다. 입력하기 불편하다는 이유만으로 맞춤법 오류나 AI 작성의 증거로 보지 않는다.

## Source usage and rights

이 항목은 확인한 공식 안내와 이 스킬의 배포 방식을 설명하며 법률 판단을 제공하지
않는다. 자료의 공개 열람, 무료 제공, 원문 복제와 재배포, AI 학습은 같은 권한이 아니다.
확인하지 못한 허가를 추정하지 않는다.

이 저장소의 **MIT 라이선스는 스킬의 자체 작성 콘텐츠에 관한 것**이다.
참고한 외부 자료의 권리를 변경하거나 해결하지 않는다. 스킬은 독창적인 지침,
요약, 비교와 예제 및 링크로 구성한다. 외부 표준의 전체 규칙, 사전, 원문이나
이를 재구성한 대체물을 배포하지 않으며 기관 로고와 인증 표지도 사용하지 않는다.

### ASD-STE100

[공식 다운로드 및 이용 안내](https://www.asd-ste100.org/STE_downloads.html)는
무료 공식본을 신청할 수 있다고 설명한다. 동시에 안내 자체는 라이선스나 개별
사용 허가가 아니며 해당 판본의 Copyright Statement가 기준이라고 밝힌다.
권리를 유보하고 상표, 도구의 승인, 인증이나 제휴를 암시하는 사용을 경계한다.

무료 제공을 규칙과 사전의 재배포 또는 AI 활용에 대한 포괄적 허가로 해석하지 않는다.
이 스킬은 전체 판본의 Copyright Statement를 검토하지 않았으므로 세부 허용
범위를 단정하지 않는다. 공개 설명을 선별 참고했을 뿐 STE를 대체하거나 한국어
결과물의 준수를 인증하지 않는다.

### ISO 24495-1

[ISO 저작권 안내](https://www.iso.org/copyright.html)는 웹 콘텐츠와 출판물의
저작권 보호 및 허가 없는 복제와 배포 금지를 설명하고 허가 문의 경로를 안내한다.
[ISO와 IEC의 라이선스 안내](https://www.iso.org/publication/PUB100206.html)도
함께 참고한다.

공개 소개를 볼 수 있다는 사실은 표준 본문 재배포 허가가 아니다. 이 스킬에는
표준 본문을 포함하지 않으며, 전문 조문과 개별 라이선스를 검토했다고 주장하지
않는다. 확인하지 못한 AI 관련 허용 또는 금지 조건도 추측하지 않는다.
독자 중심의 편집 원칙을 활용하는 것과 ISO 적합성을 인증하는 것은 다르다.

### 국립국어원 어문 규범과 일반 누리집

[어문 규범 도움말](https://korean.go.kr/kornorms/help/helpView.do)은 개인 활용에
관한 질문에서 공개 자료의 자유로운 활용을 안내한다.
[국립국어원 저작권 정책](https://www.korean.go.kr/front/nuri/pageView.do?page_id=P000189&mkn=3)은
저작권법 제24조의2에 따른 공공저작물 자유이용과, 별도로 공공누리 유형이 표시된
경우 해당 조건을 준수해야 한다는 점을 설명한다.

자료 전체가 하나의 공공누리 유형이라고 단정하지 않는다. 개별 자료의 표시와
외부 출처를 확인한다. 일반 안내와 개별 조건의 적용 대상이 불명확하면 이를
밝히고 포괄적인 재배포 허가를 주장하지 않는다.

정책의 AI 유형은 해당 표시가 있는 자료의 학습용 이용 조건이다. 학습 목적의
출처 생략과 다른 목적의 출처 의무를 구분하고, 유사한 산출물 방지와 인용 출처,
학습용 데이터 재판매 등에 관한 조건도 확인한다. 이 표시를 모든 자료나 일반적인
스킬 배포에 적용되는 무조건적 허가로 확대하지 않는다.

### 사전과 용어 서비스의 별도 조건

[표준국어대사전 및 우리말샘 대상 정책](https://www.korean.go.kr/front/page/pageView.do?page_id=P000508)은
별도 표시가 없는 자료에 **CC BY-SA 2.0 KR**을 적용한다고 설명하며 저작자 표시와
동일조건변경허락을 요구한다. 멀티미디어에는 개별 조건이 있고, 출전이 있는 용례는
원저작자의 권리를 별도로 확인해야 한다. 이 사전 정책을 어문 규범 전체의
라이선스로 일반화하지 않는다.

온용어도 항목별 출처와 이용허락을 확인한다. 용어를 조회하고 원문 링크를 안내하는
것과 사전 항목을 모아 배포하는 것은 다르다. 이 스킬은 사전 원문과 용례를
묶어서 제공하지 않는다.

## Evaluation limits

[평가용 사례](../evals/evals.json)는 기술 의미 보존, 허용 표기, 최소 교정,

입력이다. JSON 구조 검사는 모델 출력의 정확성이나 스킬 활성화를 검증하지 않는다.
