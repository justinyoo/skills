# 한국어 기술 글쓰기

[English](README.md) | 한국어

## 이 스킬의 용도

한국어 기술 글을 작성, 교정, 윤문하거나 검토할 때 의미, 사실, 용어와 보호 대상 표현을 보존합니다. 같은 한국어 글쓰기 원칙을 메일, 공지, 제안서와 에세이에도 적용하되, 기술 매뉴얼 형식을 강제하지 않습니다. 실행 스크립트나 패키지, 외부 교정 서비스는 필요하지 않습니다. 파일은 사용자가 명시적으로 요청한 경우에만 변경하며, 검토만 요청하면 원문을 그대로 유지합니다.

ASD-STE100이나 ISO 24495-1만으로는 이 스킬이 목표로 하는 한국어 글쓰기를 충분히 지원할 수 없습니다. STE는 영어 통제 언어이므로 그 규칙과 사전을 한국어에 그대로 옮길 수 없습니다. ISO의 독자 중심 쉬운 언어 원칙만으로 한국어의 맞춤법, 띄어쓰기, 자연스러운 표현이나 기술적 사실의 정확성을 판단할 수는 없습니다. 따라서 이 스킬은 국립국어원 자료를 바탕으로 한국어 표기, 조사와 의존 명사, 보조 용언, 전문 용어, 문장 부호와 허용 표기에 대한 판단 근거를 보강합니다.

자료별 역할과 한계는 [근거 비교](references/sources.md#comparison)에서, 기준이 되는 작업 흐름은 [SKILL.md](SKILL.md)에서 확인할 수 있습니다. [자료 사용 조건과 권리 안내](references/sources.md#source-usage-and-rights)는 ASD, ISO와 한국어 자료의 이용 조건을 이 스킬의 자체 작성 콘텐츠에 적용되는 MIT 라이선스와 구분해 설명합니다. 외부 표준이나 사전은 함께 배포하지 않으며, 기관의 승인이나 적합성 인증을 받았다고 주장하지 않습니다.

## GitHub Copilot CLI로 설치

GitHub Copilot CLI가 설치되어 있다면 터미널에서 다음 명령을 실행합니다.

```sh
copilot plugin marketplace add justinyoo/skills
copilot plugin install korean-technical-writing@justinyoo-skills
```

마켓플레이스를 이미 등록했다면 첫 번째 명령은 건너뜁니다. 전체 컬렉션을 설치했다면 이 스킬도 이미 포함되어 있습니다.

다른 에이전트, 설치 방법과 로컬 체크아웃에 관한 내용은 [스킬 설치 가이드](../../docs/skills-installation-guide.md)를 참고합니다.

## 사용법

GitHub Copilot CLI 세션에서 다음과 같이 요청합니다.

```text
/korean-technical-writing 다음 기술 안내문을 윤문해 주세요. 조건과 의무를 유지하고 결과는 대화에만 보여 주세요: "백업이 완료된 경우에만 설정을 변경할수 있습니다. 변경한 뒤에는 서비스를 다시 시작해야 합니다."
```
